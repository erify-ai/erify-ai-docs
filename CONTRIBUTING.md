## 🛠 How to Contribute  

1. **Fork & Clone**  
   ```bash
   git clone https://github.com/erify-ai/erify-ai-docs.git
   cd erify-ai-docs

	2. Branching
	• main → Eternal Crown (production docs)
	• dev → Flame Forge (active work)
	• feature/* → New contributions

   git checkout -b feature/add-new-guide


	3. Commit Style
Use emojis + clarity:
	• 👑 feat: new feature
	• 💎 docs: new or updated docs
	• 🔥 fix: bug fix
	• ⚡ chore: maintenance
Example:

   git commit -m "💎 docs: add ERIFY™ quick start guide"


	4. PR Process
	• Push branch
	• Open PR to dev
	• Use PR template

⸻

✅ Standards
	• Markdown linting (MDX / Prettier)
	• Screenshots for visual changes
	• Clear explanations for guides
